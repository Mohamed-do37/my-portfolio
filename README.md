# Mohamed Dogheim — Personal Portfolio

> Personal portfolio website for presenting my background, technical interests, selected projects, and contact information.

## Overview

This repository contains the source files for my personal portfolio website. The current page is organized into sections for:

- Introduction
- About
- Experience
- Skills
- Projects
- Contact

The portfolio is intended to provide a clear overview of my work across data analytics, AI, and machine learning. Project details and claims should reflect the actual state of each project.

## Run locally

### Requirements
- Node.js and npm (for the local static server)

### Start the site

```bash
npm run start
```

The start script uses `npx serve .` to serve the current directory. Open the local URL printed in your terminal.
